# Protocol references and acknowledgements

CMF Companion is unofficial and is not affiliated with or endorsed by Nothing Technology Limited or CMF. Product names identify the compatible hardware. The icon is drawn locally using Apple's SF Symbols; no Nothing/CMF product images or fonts are bundled.

The implementation was informed by these public protocol implementations:

- [Ear (web), radiance-project](https://github.com/radiance-project/ear-web), AGPL-3.0. Reference revision `d076e1371572fbf0a14b441f9b3cafbf9a237e04`: B179 model configuration, custom EQ serialization and frequencies, listening modes, multipoint, feature flags, and noise-control gesture cycles. This project's AGPL license is included in the app bundle.
- [BudsLink, maniacx](https://github.com/maniacx/BudsLink), GPL-3.0. Reference revision `af3a4998bffa1330d24a93883c707facf5b5066c`: CMF Buds 2 capability and gesture maps, control command IDs, battery parsing, and multipoint.
- [Nothing X Mac, Younes Khelifi / Senooy](https://github.com/Senooy/nothing-x-mac), MIT. Reference revision `712fc51e6230bf34c736473cc159f7287892d706`: macOS IOBluetooth RFCOMM transport, Bluetooth privacy permission gate, packet framing, and CRC parser. MIT notice follows.
